## 🧮 Modern Calculator

A simple and modern calculator web application built using **HTML, CSS, and JavaScript**.  
It performs basic arithmetic operations with a clean UI and smooth user experience.

### ✨ Features
- Basic operations: Addition, Subtraction, Multiplication, Division
- Clear (C) button to reset calculations
- Error handling for invalid expressions
- Responsive and modern UI design

### 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
